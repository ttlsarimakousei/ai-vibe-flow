## 要定的（仓库主人 2026-11-12 夜里在提问框里选的）

1. 核验期报了问题怎么进自动：**每次先问**（替代 11-12 的"照旧自动修"）。
2. 提交的认法：**只放宽提交**，推送、归档不动。
3. 只让启动却改代码：**钩子拦一次**。
4. 审查超时上报：**只报套件这头慢的**。

Claude 自己定的（写进 decisions.md）：一个用户回合只问一次、套件关自动的那一轮不问、说过停的不问；任务都做完了审查或自测催 3 次没动就关自动并让模型告诉用户；提问框选探索主要看答案，只有"探索"两个字的不让钩子自己把会话记成在流程里。

- 出错放行：新加的判断都包在 try 里，判断不了就按不拦、不关、不问处理——`askPending` 找不到这一轮的开头不问，`blockOnce` 记不了放行，`giveUp` 抛了错不拦，`syncEntryAnswer` 出错不记。

自审时改的四处：
