## A 安全和红线

- **A1 push 确认**：guard-commit 认出任何写法的 git push（`-C`、`--git-dir`、`-c`、cd 之后、`cmd /c`、`bash -c`、`powershell -Command` 里面），返回"要你确认"（permissionDecision: ask）。权限规则 `Bash(git push:*)` 留着当第二道。
- **A2 disableAllHooks**：写任何 `.claude/settings*.json`（项目级、用户级）时，新内容里出现 disableAllHooks 就拦；命令里出现也拦。
- **A3 heredoc 提交**：多行提交信息只判信息，判完接着检查同一条命令里的 add。
- **A4 commit -a / add -u**：拦下，提示只 add 这一轮改的文件。
- **A5 整仓 add**：`-Av`、`-vA`、`:/`、`./*`、`.`、壳子里 add 子项目目录，都按"整仓 add"处理；认子项目时不再跳过叫 docs、templates 的目录。
- **A6 命令解析**：按工具区分 Bash 和 PowerShell 的转义规则；先合并续行；认 `-m"x"`、`-mx` 紧贴写法；`cmd /c`、`bash -c`、`powershell -Command` 里的命令再解析一遍；cd 名单加 Push-Location。
- **A7 禁止改套件的命令检查**：只把标准输出重定向当写入（`2>&1`、`2>$null` 不算）；认紧贴的 `>~/...`；管道后面的删除、写入命令也拦；`find -delete/-exec` 不算只读；`$home` 不分大小写；heredoc 和 here-string 的正文不当命令拆词；只读名单补 Get-Item、jq。
- **A8 目录联接**：受保护路径同时认原样路径和真实路径，要判断的路径也先解析成真实路径再比。

## B 流程卡死

- **B1 审查记录只看"真审了"**：每次收工（包括续跑）都扫这一轮的 vibe-reviewer 调用，有结果、不是报错、带"结论：问题 N 条"的才记。模式按提示第一行"模式：提案 / 代码 / 复审提案 / 复审代码"认；变更按提示里点名的认，没点名的不记到任何变更头上。
- **B2 催和记分开**：催审代码只记"催过"的时间；归档门槛要求"审过"，而且审查时间晚于"做完"的时间；不看自动交叉审查开关，手动审也算。
- **B3 兜底**：第一次打勾找不到审提案的记录时，去会话记录里找一次成功的审提案调用。
- **B4 多轮审查**：记下已计过的审查调用，只累加新的；没有新审查就不重置、不重催；每轮最多催一次；轮数用完问一次（全自动自己定），之后只有出现新的审查才开始新一轮计数。
- **B5 状态清理**：只清按会话命名的文件；全局记录（审查、催过、计划提醒、网关）不按文件时间删，条目 60 天后清。
- **B6 同名变更**：记录里带上变更目录的创建时间，对不上就当没有。
- **B7 配置页保存**：接口改成只合并传进来的字段；页面保存成功后用返回值刷新缓存。
- **B8 状态文件**：原子写（先写临时文件再改名）；读失败返回"读不了"，调用方不写回，免得把别人的记录冲掉；键统一做大小写归一化。

## C 误拦和漏拦

- **C1 打勾检查**：失败的编辑不算"上次打勾"；按任务编号认打勾（行尾加字也认得）；只有成功的命令才算跑过验法；验法按"命令位置"匹配工具名，不按子串。
- **C2 CRLF 和弯引号**：模拟编辑前统一换行，匹配不到再试引号归一化。
- **C3 含糊词**：改成整句短语（"之后再说""以后再定"…）；引号里的业务状态名、"变为 / 改为…"后面的不算；"按钮"不算"按…做"。
- **C4 找文件**：只写文件名时不限深度，每个根目录单独预算；预算用完还没找到就不拦，只提示"写全相对路径"。
- **C5 路径提取**：支持中文文件名、`@/` 别名、以 `/` 开头的源码路径。
- **C6 设计依据、能力检查**：每轮最多拦一次；"读过"认带 path 的 Grep/Glob，和命令里任何位置的 cat、Get-Content。
- **C7 交接后的新会话**：有一天内的交接记录、或这一轮是交接续接时，探索和提案不要求分轮。
- **C8 全自动的"卡住"判断**：只认"卡住、无法继续、需要你决定、不可逆"这类明确说法，排除"等你回来定的事"这个标题。
- **C9 续跑里改了代码**：上次拦下之后又改了代码、没跑验证的，再查一次；只有改了新代码才会再拦，不空转。
- **C10 编码**：`.vibe/`、`.claude/`、`openspec/`、CLAUDE.md 跳过"目录以 GBK 为主"的判断；周围没有样本时先看 pom.xml / build.gradle 声明的编码，还判断不了就不给转码建议，让它停下来问。
- **C11 交接**：模型用 Skill 调 handover、或者写过 `.vibe/handover.md` 的会话，都算"写交接记录的会话"；判过期只看交接记录里提到的变更。
- **C12 交接提问**：你选过"再做一会儿"的，每条消息只说"已过线，到 N% 再问"；压缩后清掉"问过"的记录；压缩摘要不算用户消息；取不到本轮边界时退回按"是不是续跑"判断。
- **C13 上下文**：分母取配置的上限和 Claude Code 报的窗口里较小的那个。
- **C14 提示规则**：只看路径（Grep 只看结果里的文件名）；"."开头的按扩展名匹配，其余按路径片段整词匹配；配置页示例规则去掉 ddl、schema。
- **C15 .gitignore**：认出 `.vibe/*`、`/.vibe/**`、带 BOM 的写法，不重复追加；写入被拦时不改 .gitignore。
- **C16 源码判断**："不是源码"只排除仓库根下的 docs；"不适用"按被改文件所在子项目的项目说明判断。
- **C17 归档门槛**：取变更名时跳过 `-y`、`--yes` 这类参数；mv、Move-Item 的源路径按 cd 之后的目录解析。

## D 模型路由和配置页（助手做）

- **D1** 删掉"客户端等久了断开就冷却模型"这条规则，只在用量里记"客户端取消"。
- **D2** 路由启动时写 pid 文件（带令牌）；停止时先请它自己保存退出，等不到再按 pid 结束；netstat 只认 `127.0.0.1:端口` 那一行。
- **D3** 转发路径上带 Origin、Sec-Fetch-* 头、或者不是 JSON 的请求一律 403。
- **D4** 行为参数清空时传空串，服务端按默认值处理。
- **D5** 大请求遇到网关 502/504，也走"先回给客户端、连续两次才换"。
- **D6** 每次换模型前重新检查冷却。
- **D7** 流里的 error 事件记成失败（overloaded 冷却），没有 message_stop 记成传输中断。
- **D8** 取消的请求也记用量，写成"客户端取消"；流式中途取消不再写成"上游中途断开"。
- **D9** 换端口后"断开"能恢复原来的地址：当前地址是本机回环地址时，不覆盖记下的原地址。
- **D10** 技能下拉框有内容；模型测试结果不被刷掉；out.log 不无限增长；用量文件原子写，退出时保存。
- **D11** 429、529、带 retry-after 的 503：预算内先在原模型等；冷却时长按 retry-after 算（10 到 300 秒）。
- **D12** 所有请求的等待都封顶在客户端超时减 20 秒。
- **D13** 配置页的选目录、自动探测、技能清点放到工作线程里做，加超时，不卡转发。
- **D14** 按模型加"校验证书"开关，默认保持现在的不校验（内网常见自签证书），页面上说明风险。
- **D15** 保存配置带版本号，版本不一致就拒绝并提示刷新。
- **B7** 配置页保存的问题也在这一组做。

## G 性能和架构

- **G1 钩子改走 HTTP**：路由进程里起一个工作线程运行钩子，高频钩子（改文件、跑命令、提问框、读文件提醒、收工）登记成 HTTP 钩子；会话开始、用户开口两个保留命令方式，并负责让路由活着。装了路由才用 HTTP，没装路由的照旧用命令方式。配置页加"钩子运行方式：自动 / HTTP / 命令"，并显示最近一次收到钩子调用的时间。用户开口时自检：这一轮改过文件或跑过命令、路由却没收到钩子调用，路由没在跑就拉起来，路由在跑就自动切回命令方式并提醒。
- **G2** 改文件的三个检查合成一个入口，命令方式和 HTTP 方式都只调一次。
- **G3** 收工时 git status 加 `--no-optional-locks`；一次收工里变更列表只算一次。
- **G4** 产物指纹按修改时间缓存，没变的文件不重算哈希。
- **G5** 状态栏的变更进度缓存几秒。
- **G6** guard-commit 的受保护路径每个进程只算一次；heredoc 正文不拆词。
- **G7** 编码普查的总读取数设上限。
- **G8** 打断后重扫整份会话记录的结果，按文件大小缓存。
