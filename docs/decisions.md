# 设计决定

为什么是现在这样。标着"用户定的"的，是仓库主人明确说过的，**不要改回去**；觉得有问题，写清理由交给他定。没标的是做的时候的取舍，有更好的办法可以改，改了在这里记一笔。

## 方向

| 日期 | 决定 | 谁定的 | 为什么 |
|---|---|---|---|
| 2026-09-03 | 做一套轻量的 vibe coding 工作流，代替原来那套很重的项目脚手架（约 5 万行、三模型审核、双闸门）。只在 Claude Code CLI 上用，后面是内网私有模型 | 用户定的 | 原来那套太重 |
| 2026-09-03 | 原则：确定性的事外置给脚本（编号、状态、git、编译、起停服务、截图）；验证靠能执行的检查；一个项目一份配置；视觉最后由人裁决 | 一起定的 | 模型会忘、会想当然，脚本不会 |
| 2026-09-05 | 页面验证默认用"模型写场景文件、脚本执行"，让模型直接驱动浏览器（MCP）只做探索性排查 | 体检结果 | 内网体检：写场景 18/18 一次过；MCP 直驱 15/18，瞬时提示抓不到时会重复操作 |
| 2026-09-12 | 设计图还原靠数字对比（布局树、像素比对），不靠让模型读截图复刻 | 团队规定 | "还原度应该由工程化手段解决" |
| 2026-09-18 | 测试阶段结束，两个体检包冻结，回到做工作流本身 | 用户定的 | 一直在打磨测量工具，偏离了初衷 |
| 2026-09-19 | 挂在 OpenSpec 1.2 上，不另起需求、任务、状态管理 | 团队规定 | 公司强制用 OpenSpec |
| 2026-09-19 | 不做桌面应用，界面是路由提供的本机网页 | 一起定的 | 装起来简单，没有窗口 |
| 2026-09-19 | 套件里任何花 token 的设计（子代理、读截图、每条消息注入）都要说得清成本、能关掉；不新开子代理 | 团队规定 | 每人有 token 额度，严禁随意开子代理 |

## 保护和放行

| 日期 | 决定 | 谁定的 | 为什么 |
|---|---|---|---|
| 2026-09-23 | 禁止模型改套件自己的文件（`kitLock` 默认开），套件有问题让它记问题反馈 | 用户定的 | 用户发现 Claude 嫌钩子碍事，自己去改了钩子 |
| 2026-09-24 | git push 不管怎么写都弹确认框 | 取舍 | 权限规则按前缀匹配，`git -C 子项目 push` 绕得过去 |
| 2026-09-28 | 令牌和模型的 key 模型读不到：权限规则、`guard-read`、`guard-commit` 三道 | 用户定的 | |
| 2026-09-30 | 令牌保护只放宽了"整条命令只是列目录、按名字找、过滤名单"这一种，**不再往宽里放** | 用户定的 | |
| 2026-09-30 | 自动更新的两条安全设计先不动：安装包没有完整性校验、令牌走 http、https 不验证书；git 低于 2.31 时令牌出现在命令行上 | 用户定的 | |
| 2026-09-30 | Bash 里 cd 和别的命令串在一条里就拦下，给出不用 cd 的写法 | 用户实测确认后做的 | 这种命令在跳过权限模式下也弹确认框，全自动时会一直挂着 |
| 2026-09-30 | 数据库、redis 的口令不经过模型、不上命令行；厂商的 JDBC 驱动不进安装包 | 用户定的 | 驱动只限内部使用 |
| 2026-10-01 | 维护套件的电脑的地址写死在 `kit/lib/gitlab.js`，配置页上不再有这一项 | 用户定的 | 不让别人在配置页上看到 |

## 全自动模式

| 日期 | 决定 | 谁定的 | 为什么 |
|---|---|---|---|
| 2026-09-29 | 全自动模式下一切自动：不弹提问框、被流程类的检查拦下可以自己放行、收工时交一份报告 | 用户定的 | 开会、下班时用，不能停在提问框上等一夜 |
| 2026-09-29 | 全自动模式下仍然拦、不能放行的：改套件、读令牌和 key、结束路由进程、整仓 add、改非 UTF-8 文件、push | 取舍 | 这些做错了收不回来 |
| 2026-09-30 | **全自动模式只在走 OpenSpec 流程的会话里算数** | 用户定的 | 另开的检索窗口收工时自己去接着做没做完的变更，差点和正在做的窗口打架 |
| 2026-09-30 | 全自动模式下改库不再一律拒绝：留得下改前快照和还原脚本的就做；redis 的写操作不放开 | 用户定的（改库）+ 取舍（redis） | redis 没有改前快照 |
| 2026-09-30 | 变更的过程文件留到变更归档，归档后套件自己清 | 用户定的 | 全自动过程中模型把还要用的过程文件删了 |
