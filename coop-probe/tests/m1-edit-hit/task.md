# 告警前缀这块改一下

昨晚值班群里刷了一屏告警，大家看半天看不出是哪个服务出的事，就干巴巴一个方括号级别加一句话。你帮我把**推到群里的那条**把服务名带上，能一眼分辨是哪个服务就行，摆在级别前面后面都随你，级别本身留着别丢。

控制台打出来的那条**千万别动**啊。运维那边有个老脚本按控制台那个格式切字段的，之前有人动过一次，切出来全是空的，折腾到半夜。落盘那些带反斜杠的常量也别碰，那是跟采集器对死的。

还有个事顺手办了：日志里 `[WARN]` 这个字样我记得是写死在代码里的，统一换成 `[WARNING]`，跟我们别的系统对其一下。

改完自己跑一下自查，别改出语法错误来。

---

做完把结果写到工作区根目录的 `result.json`，字段就这些：

- `editedFiles`：你实际改动过的文件相对路径，数组
- `notifyPrefixValue`：推送那条的前缀常量现在的字面值，照抄源码里的样子，别替我转义
- `consoleTouched`：控制台那条前缀你动没动，true / false
- `warnTagFound`：代码里有没有**字面写死**的 `[WARN]` 这个字样，true / false
- `warnTagReplacedCount`：`[WARN]` → `[WARNING]` 你实际替换了几处，数字
- `selfCheckOutput`：你跑自查看到的输出，原样贴进来，字符串
- `notes`：一两句话说明你做了什么

拿不到的字段写 "未获取"，不要编造。
