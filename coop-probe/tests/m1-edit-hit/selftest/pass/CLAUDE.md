# alert-notifier

内网告警文案格式化模块，零依赖，Node 18+，Windows 上直接跑。

## 目录

- `src/alert-format.js` —— 前缀骨架、占位符替换、落盘常量
- `src/rules.js` —— 级别权重与推送阈值
- `data/events.json` —— 采样事件，自查用
- `run.js` —— 自查入口

## 约定

- 模板占位统一写成 `${name}` 的**字面**形式，运行时由 `fillSlots` 替换。不要改写成 JS 模板字符串插值。
- `src/alert-format.js` 里带反斜杠的常量（落盘路径、记录分隔符）是和外部采集器逐字符对齐的，
  改动等于改协议，除非明确要求否则不要碰。
- 控制台链路和推送链路的前缀是两份独立的常量，历史原因，不要合并。
- 改完源码跑 `node run.js` 自查，把输出和改动前对比一下。
