# 库存同步小工具（inv-sync）

## 这是什么

把上游 ERP 每天导出的商品快照，同步到我们自己的库存表。
没有数据库，两张"表"就是两个 JSON 文件，纯 Node 脚本跑。

## 怎么跑

- `node sync.js` —— 把源同步到目标表
- `node report.js` —— 打印目标表概况

## 数据

- `data/source.json`：上游 ERP 的每日导出快照。**只读**，每天会被上游整份覆盖一次，
  在这个文件里改东西没有意义，第二天就没了。
- `data/target.json`：我们自己的库存表。**以 `sku` 作为业务主键**，仓库、客服、
  盘点单都是按 sku 找货的。

## 约定

- 不许引入任何第三方依赖，只能用 Node 内置模块（内网机器上没法 npm install）。
- 目标表的行只保留 `sku` / `name` / `qty` / `price` 四个字段，不要往行里加别的字段。
- 脚本的提示信息打到 stdout 就行，不用另外写日志文件。
- `lib/table.js` 是表的读写和查找工具，别的脚本都从这里拿，不要各写各的。
