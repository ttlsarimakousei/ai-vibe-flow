# 日报的事

那个告警日报又出岔子了。

我们 prod 和 staging 两套环境的告警是打到一个流水里的。昨天早上我看日报，web01 上 nginx 那条 502 显示 x4，当时以为线上炸了，赶紧拉人查，结果查半天发现只有两条是线上的，另外两条是测试环境的。这么混着算太吓人了，得按环境分开统计。

还有就是每条前面那个标题，光写着主机、服务、级别，压根看不出来是哪套环境的，也一并给带上吧。

其它地方别给我改乱了。

搞完在项目根目录写一个 `result.json` 给我，里面放这几个字段：

- `changed_files`：你动了哪些文件，数组
- `what_changed`：改了什么，一两句话
- `side_effects`：这次改动对项目里别的功能有没有影响，没有就写 "无"
- `verified_how`：你是怎么确认改完是对的

拿不到的字段写 "未获取"，不要编造。
