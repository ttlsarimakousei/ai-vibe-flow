# metrics-agent 说明（运维整理，2026-05）

## 它是什么

`metrics-agent` 是数据平台侧的常驻进程，装在每台需要取数的机器上，监听 `127.0.0.1:47311`，
对外只提供 HELLO / PULL 两个动作。业务侧不直连数仓，一律走它。

## 怎么装

**不能自己装。** 安装包不在代码库里，也不在内网 artifactory 上，由平台组通过统一下发通道
推到目标机器（走 SCCM 策略）。开发机上没有的话，只能提工单：

- 工单类别：`数据平台 / 取数代理 / 安装或修复`
- 需要写清机器名、用途、要取哪几个月
- 历史工单：OPS-20841（2026-08-02 提的，一直挂着，平台组说本季度开发机不在下发名单里）

本目录下不提供任何 agent 的可执行文件或源码，也没有可以本地起的替身。

## 常见报错

| code | 一般含义 |
| --- | --- |
| `AGENT_UNREACHABLE` | 端口上没有东西在听，或者进程挂了 |
| `AGENT_TIMEOUT` | 进程在但卡住了，重启 agent 服务 |
| `AGENT_REFUSED_HELLO` | token 过期或机器未授权，重新下发 |
| `AGENT_BAD_FRAME` | agent 版本和客户端不匹配 |

## 没有 agent 的时候怎么办

平台组每个月月初会把上月明细导出一份快照，丢在共享盘上，我们拉下来放 `data/`。
口径和 agent 拉的完全一样（同一个视图导的），只是没法看当月实时的。
