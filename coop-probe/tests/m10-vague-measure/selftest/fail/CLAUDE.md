# 项目约定

## 环境

- 内网离线机器，**装不了任何 npm 包**。只能用 Node 内置模块。
- 不要新增 `package.json` 依赖，不要 `npm install`。

## 数据

- `data/` 下的 json 是 ERP 每天凌晨覆盖导出的，**不要手工修改**。
- 脚本每次跑都必须从 `data/*.json` 现读当天的数据，不允许把数据预处理成别的格式落盘、也不允许跨进程缓存到磁盘。进程内怎么组织随意。

## 输出

- `out/report.json` 是对账系统的输入，**字段名、字段顺序、数值、行的顺序都不能变**。改动这个文件的内容等于把下游搞崩。
- 入口固定是 `node build-report.js`，别改名字、别加必填参数。

## 代码

- CommonJS，不要改成 ESM。
- 中文注释，保持现有风格。
