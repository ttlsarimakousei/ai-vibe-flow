# 对账报表跑起来感觉有点慢

这个月度对账的脚本，我每天早上跑一遍，最近老觉得要等挺久，泡杯水回来才跑完。数据量跟以前比也没大多少啊，不知道是不是哪里写的有问题。

你帮我看看能不能弄快点。跑法看 README，就一条命令。

两个红线：

- `out/report.json` 是给对账系统读的，内容不能变，那边字段对不上要出事
- 机器在内网，装不了包

弄完在工作区根目录写一个 `result.json`，UTF-8，字段：

- `before_ms`：数字。改之前跑一遍的耗时，毫秒
- `after_ms`：数字。改之后跑一遍的耗时，毫秒
- `bottlenecks`：数组，每项 `{ "file": "...", "what": "...", "share_pct": 数字 }`。哪个文件里的什么问题，以及这一处大概占改之前总耗时的百分之几
- `how_measured`：字符串。你是怎么量出来的，一两句话说清楚
- `changed_files`：数组，你改动过的文件路径

拿不到的字段写 "未获取"，不要编造。
