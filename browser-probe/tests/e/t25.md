# 任务 e/t25：老系统（树菜单、iframe、慢加载、详情跳转、慢导出）

方式：写场景文件，用场景执行器跑（第二点五档）。不要用 Bash 直接开浏览器，不要修改 tools/ 下的脚本。

站点 http://127.0.0.1:4173，账号 admin / admin123。登录后用 goto 打开 /e/index.html。

先读 `scenarios/README.md`（注意 `frame` 步骤）。可参考 `scenarios/sample-e-legacy.json`，但本任务看的是第 3 行工单，顺序也不同。

页面结构：左侧树菜单里点"工单管理"展开，再点"工单查询"（`#mTickets`），内容会加载到 iframe `#main` 里。iframe 里：工单表 `#ticketTable`（接口故意慢 1.5 秒），每行最后一列有"详情"链接；详情页里状态在 `#status`，返回按钮 `#backBtn`；导出按钮 `#exportBtn`（故意慢 2 秒），结果文字在 `#exportMsg`。

场景文件写到 `scenarios/model-e-t25.json`，依次做到：

1. 登录，打开 /e/index.html，点"工单管理"，点"工单查询"
2. 进入 iframe `#main`，等工单表出现，读数据行数 → `ticketRows`
3. 点第 3 行的"详情"，等详情表出现，读状态 → `detailStatus`
4. 点"返回列表"，等导出按钮出现，点"导出 Excel"，等文本"文件已生成"，读 `#exportMsg` → `exportMsg`
5. 回到主页面，截图 `legacy`；断言无 console 错误

运行：`node tools/scenario-run.js scenarios/model-e-t25.json --out <场景执行器输出目录>`（没给就用 results/model/e-t25-out）。失败最多重跑 2 次。

结果文件（路径由启动提示给出；没给就写 `results/model/e-t25.json`）：

```json
{ "ticketRows": "", "detailStatus": "", "exportMsg": "", "retries": 0, "notes": "" }
```

值从 RESULT 行的 `values` 里抄。拿不到的写 "未获取"，不要编。
