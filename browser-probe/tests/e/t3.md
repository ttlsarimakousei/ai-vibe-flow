# 任务 e/t3：老系统（树菜单、iframe、慢加载、详情跳转、慢导出）

方式：只用 Playwright MCP 工具（名字以 `mcp__playwright__` 开头）直接操控浏览器（第三档）。禁止用 Bash 开浏览器，禁止 WebFetch，禁止读演示站源码推算答案。

站点 http://127.0.0.1:4173，账号 admin / admin123。登录后导航到 /e/index.html。

提示：直接调 browser_snapshot 拿带 ref 的快照；内容区是一个 iframe，它里面的内容也会出现在快照里；工单表要 1.5 秒才加载完，导出要 2 秒，快照里没看到就用 browser_wait_for 等一下。不要用截图工具。

步骤：

1. 登录，打开 /e/index.html，点左侧"工单管理"展开，再点"工单查询"
2. 等工单表加载完，数有几行数据 → `ticketRows`
3. 点第 3 行（工单号 T-1003）的"详情"，读它的状态 → `detailStatus`
4. 点"返回列表"，点"导出 Excel"，等结果出现，读出结果文字 → `exportMsg`

结果文件（路径由启动提示给出；没给就写 `results/model/e-t3.json`）：

```json
{ "ticketRows": "", "detailStatus": "", "exportMsg": "", "toolCalls": 0, "notes": "" }
```

同一个动作连续失败 3 次就停下来写结果文件；拿不到的写 "未获取"，不要猜。
