# 任务 f/t25：Vue 单页应用（动态路由、Element Plus 表格与弹窗、异步组件）

方式：写场景文件，用场景执行器跑（第二点五档）。不要用 Bash 直接开浏览器，不要修改 tools/ 下的脚本。

站点 http://127.0.0.1:4173，这一套是 Vue 3 + vue-router history 模式 + Element Plus，入口 /f/login，账号 admin / admin123。登录成功后路由会跳到 /f/users，左侧菜单是登录后按权限动态注册的。

先读 `scenarios/README.md`，重点看"语义选择器"：这套页面的输入框没有 id，用 `{"label": "用户名"}`、`{"role": "button", "name": "登录"}`、`{"placeholder": "…"}`、`{"text": "…"}` 这类写法定位。可参考 `scenarios/sample-f-vue.json`，但本任务还要做订单弹窗和校验，照抄会缺值。

页面元素提示：用户表数据行 `.user-table .el-table__row`；分页总数 `.el-pagination__total`；搜索框占位文字"按姓名搜索"，搜索按钮文字"搜索"；菜单项 `.el-menu-item`，点文字"订单管理"切换页面；订单页按钮"新建订单"打开弹窗（弹窗挂在 body 下），弹窗里表单项标签为 客户名称 / 产品 / 数量 / 加急 / 备注，校验错误文字在 `.el-form-item__error`；产品是 el-select，先点 `.el-dialog .el-select` 打开下拉，再点选项 `{"role": "option", "name": "机械键盘"}`，不要按文字找，后面的订单表里也有同名单元格会先被命中；保存按钮文字"保存"；成功提示在 `.el-message`；订单表数据行 `.order-table .el-table__row`；菜单"经营报表"是异步组件，加载要两秒左右，报表数字 `#reportOrders`。

场景文件写到 `scenarios/model-f-t25.json`（建议加 `"disableAnimations": true`），依次做到：

1. 打开 /f/login，登录，等地址变为 /f/users，等用户表数据行出现
2. 读菜单项数量 → `menuItems`；读分页总数文字 → `total`
3. 搜索框输入 王，点搜索，等 400 毫秒，读数据行数 → `searchRows`
4. 点菜单"订单管理"，等订单表出现；点"新建订单"，什么都不填直接点"保存"，读第一条校验错误文字 → `formError`
5. 填客户名称 华兴电子，产品选 机械键盘，点"保存"，等文本"订单已创建"出现，读 `.el-message` 文字 → `createMsg`，读订单表数据行数 → `orderRows`
6. 点菜单"经营报表"，等 `#reportOrders` 出现，读它 → `reportOrders`
7. 输出布局树 `report`（root 为 `.view-report`）；断言无 console 错误（可忽略 `\\[Vue warn\\]`）

运行：`node tools/scenario-run.js scenarios/model-f-t25.json --out <场景执行器输出目录>`（没给就用 results/model/f-t25-out）。失败最多重跑 2 次。
