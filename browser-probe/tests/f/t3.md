# 任务 f/t3：Vue 单页应用（动态路由、Element Plus 表格与弹窗、异步组件）

方式：只用 Playwright MCP 工具（名字以 `mcp__playwright__` 开头）直接操控浏览器（第三档）。禁止用 Bash 开浏览器，禁止 WebFetch，禁止读演示站源码推算答案。

站点 http://127.0.0.1:4173，这一套是 Vue 3 单页应用 + Element Plus，入口 /f/login，账号 admin / admin123。登录后自动进入用户管理页，左侧菜单是登录后按权限动态生成的。

提示：直接调 browser_snapshot 拿带 ref 的快照；页面切换、表格加载、弹窗打开都是异步的，快照里没看到就用 browser_wait_for 等一下再取；"经营报表"是异步组件，要等两秒左右；产品下拉是 combobox，点开后再点快照里 option 角色的"机械键盘"，注意订单表里也有同名文字，别点错。不要用截图工具。

步骤：

1. 打开 /f/login，登录，确认进入用户管理页
2. 数左侧菜单有几项 → `menuItems`；读分页区域"共 N 条"那一整句 → `total`（原样抄整句，例如「共 12 条」这种格式）
3. 在搜索框输入 王，点搜索，数表格有几行数据 → `searchRows`
4. 点菜单"订单管理"，点"新建订单"，什么都不填直接点"保存"。表单会出现多条校验错误，只读"客户名称"那一项下方的那条 → `formError`
5. 填客户名称 华兴电子，产品选 机械键盘，**只点一次"保存"**。成功提示是几秒就消失的 ElMessage，点保存之后立刻用 browser_wait_for 等文字"订单已创建"再取快照。如果还是错过了，**不要再次提交订单**，改为读订单表第一行的订单号，按「订单已创建：<订单号>」的格式拼出来 → `createMsg`
6. 点菜单"经营报表"，等它加载完，读"本月订单"的数字 → `reportOrders`
