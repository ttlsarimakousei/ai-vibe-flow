# 任务 c/t3：商品列表（分页、搜索、确认框删除）

方式：只用 Playwright MCP 工具（名字以 `mcp__playwright__` 开头）直接操控浏览器（第三档）。禁止用 Bash 开浏览器，禁止 WebFetch，禁止读演示站源码推算答案。

站点 http://127.0.0.1:4173，账号 admin / admin123。登录后导航到 /c/index.html。

提示：直接调 browser_snapshot 拿带 ref 的快照；点击删除后会弹出浏览器 confirm 确认框，要用 browser_handle_dialog 接受；提示文字几秒后会消失，快照里看不到时可以用 browser_evaluate 读 `#toast` 的 textContent。不要用截图工具。

步骤：

1. 登录，打开 /c/index.html，数第一页表格有几行数据（不含表头） → `firstPageRows`
2. 点两次"下一页"，数第三页有几行 → `page3Rows`
3. 在搜索框输入 键盘，点搜索，数有几行 → `searchRows`
4. 点第一行的"删除"，接受确认框，读提示文字 → `deleteToast`，读页面上"共 N 条"的文字 → `totalAfterDelete`

结果文件（路径由启动提示给出；没给就写 `results/model/c-t3.json`）：

```json
{ "firstPageRows": "", "page3Rows": "", "searchRows": "", "deleteToast": "", "totalAfterDelete": "", "toolCalls": 0, "notes": "" }
```

同一个动作连续失败 3 次就停下来写结果文件；拿不到的写 "未获取"，不要猜。
