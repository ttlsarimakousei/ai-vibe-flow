# 任务 c/t25：商品列表（分页、搜索、弹窗新增、确认框删除）

方式：写场景文件，用场景执行器跑（第二点五档）。不要用 Bash 直接开浏览器，不要修改 tools/ 下的脚本。

站点 http://127.0.0.1:4173，账号 admin / admin123。登录后用 goto 打开 /c/index.html，每次打开都会重置数据。

先读 `scenarios/README.md`（注意 `onDialog` 步骤）。可参考 `scenarios/sample-c-list.json`，但本任务多了弹窗新增，删除的时机也不同，照抄会答错。

页面元素：搜索框 `#q`、搜索 `#searchBtn`、新增 `#addBtn`、表格 `#productTable`、总数 `#total`、下一页 `#nextBtn`、弹窗里 `#pName` 名称 / `#pCat` 分类 / `#pPrice` 价格 / `#pStock` 库存 / `#saveBtn` 保存、每行的删除按钮 `.del-btn`（点击会弹出浏览器 confirm 确认框）。搜索或翻页后表格会重新加载，读数之前 `wait` 300 毫秒。

场景文件写到 `scenarios/model-c-t25.json`，依次做到：

1. 登录，打开 /c/index.html，等表格出现，读第一页数据行数 → `firstPageRows`
2. 点两次"下一页"，读第三页数据行数 → `page3Rows`
3. 搜索框输入 键盘，点搜索，读行数 → `searchRows`
4. 点"新增"，在弹窗里填 名称 体检新品、分类 配件、价格 99、库存 10，点保存，等文本"新增成功"，读 `#total` → `totalAfterAdd`
5. 用 `onDialog` accept 处理确认框，然后点第一行的删除按钮，等文本"已删除"，读 `#toast` → `deleteToast`，读 `#total` → `totalAfterDelete`
6. 截图 `list`；断言无 console 错误

运行：`node tools/scenario-run.js scenarios/model-c-t25.json --out <场景执行器输出目录>`（没给就用 results/model/c-t25-out）。失败最多重跑 2 次。

结果文件（路径由启动提示给出；没给就写 `results/model/c-t25.json`）：

