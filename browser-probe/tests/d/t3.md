# 任务 d/t3：数据看板（标签页、折叠明细、柱状图）

方式：只用 Playwright MCP 工具（名字以 `mcp__playwright__` 开头）直接操控浏览器（第三档）。禁止用 Bash 开浏览器，禁止 WebFetch，禁止读演示站源码推算答案。

站点 http://127.0.0.1:4173，账号 admin / admin123。登录后导航到 /d/index.html。

提示：直接调 browser_snapshot 拿带 ref 的快照。**本任务允许使用 browser_take_screenshot**：柱状图画在 canvas 上，快照里没有它的内容，要看图才知道哪根柱子最高；如果你不能看图，就展开"详情"从明细表里推断。

步骤：

1. 登录，打开 /d/index.html
2. 点"库存"标签，读第一张统计卡（库存总量）的数值 → `stockTotal`
3. 点"详情"展开明细表，数有几行 → `detailRows`
4. 判断库存柱状图里最高的柱子是几月 → `tallestMonth`（写成"N月"）

结果文件（路径由启动提示给出；没给就写 `results/model/d-t3.json`）：

```json
{ "stockTotal": "", "detailRows": "", "tallestMonth": "", "usedScreenshot": true, "toolCalls": 0, "notes": "" }
```

`usedScreenshot` 如实填写你有没有用截图。同一个动作连续失败 3 次就停下来写结果文件；拿不到的写 "未获取"，不要猜。
