# 任务 d/t25：数据看板（标签页、折叠明细、刷新计数）

方式：写场景文件，用场景执行器跑（第二点五档）。不要用 Bash 直接开浏览器，不要修改 tools/ 下的脚本。

站点 http://127.0.0.1:4173，账号 admin / admin123。登录后用 goto 打开 /d/index.html。

先读 `scenarios/README.md`。可参考 `scenarios/sample-d-dash.json`，但它看的是"客户"标签，本任务看"库存"标签。

页面元素：标签按钮 `.tab[data-tab="inventory"]`；库存面板第一张统计卡的数值 `#inventoryCard1`；明细折叠按钮 `#inventoryToggle`，展开后明细表 `#inventoryDetail tbody tr`；刷新按钮 `#refreshBtn`，计数文字 `#refreshCount`。

场景文件写到 `scenarios/model-d-t25.json`，依次做到：

1. 登录，打开 /d/index.html，等 `#salesCard1` 出现
2. 点"库存"标签，读第一张统计卡的数值 → `stockTotal`
3. 点"详情"展开明细，读明细表行数 → `detailRows`
4. 点两次"刷新"，读计数文字 → `refreshCount`
5. 截图 `inventory`；输出布局树 `inventory`（root 为 `#inventory`）；断言无 console 错误

运行：`node tools/scenario-run.js scenarios/model-d-t25.json --out <场景执行器输出目录>`（没给就用 results/model/d-t25-out）。失败最多重跑 2 次。

结果文件（路径由启动提示给出；没给就写 `results/model/d-t25.json`）：

```json
{ "stockTotal": "", "detailRows": "", "refreshCount": "", "retries": 0, "notes": "" }
```

值从 RESULT 行的 `values` 里抄。拿不到的写 "未获取"，不要编。
