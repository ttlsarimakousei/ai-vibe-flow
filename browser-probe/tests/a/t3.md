# 任务 a/t3：管理后台（登录、数行、导出提示）

方式：只用 Playwright MCP 工具（名字以 `mcp__playwright__` 开头）直接操控浏览器（第三档）。禁止用 Bash 开浏览器，禁止 WebFetch，禁止读演示站源码推算答案。

站点 http://127.0.0.1:4173，账号 admin / admin123。

提示：browser_navigate 可能只返回快照文件链接，直接调 browser_snapshot 拿带 `[ref=eN]` 的快照；点击、输入用 ref 作为 target。不要用截图工具。

步骤：

1. 打开 /login.html，输入账号密码，点击登录，确认进入控制台（页面上有"当前用户"字样）
2. 点击左侧菜单"用户管理"，数出表格有几行数据（不含表头） → `userRows`
3. 点击"订单管理"，再点击"导出"按钮，读出提示文字 → `toast`（提示几秒后会消失，动作要连贯；快照里看不到时可以用 browser_evaluate 读 `#toast` 的 textContent）

结果文件（路径由启动提示给出；没给就写 `results/model/a-t3.json`）：

```json
{ "userRows": "", "toast": "", "toolCalls": 0, "notes": "" }
```

`toolCalls` 填你估计的浏览器工具调用次数。同一个动作连续失败 3 次就停下来写结果文件；拿不到的写 "未获取"，不要猜。
