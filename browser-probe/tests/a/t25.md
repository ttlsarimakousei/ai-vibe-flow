# 任务 a/t25：管理后台（登录、菜单、导出提示）

方式：写场景文件，用场景执行器跑（第二点五档）。不要用 Bash 直接开浏览器，不要修改 tools/ 下的脚本。

站点 http://127.0.0.1:4173，账号 admin / admin123。登录成功后会跳到 /dashboard.html，左侧菜单是 hash 路由（`.nav a[href="#orders"]` 这种选择器）。

先读 `scenarios/README.md` 了解步骤格式。可参考 `scenarios/sample-login-users.json`，但它的目标和本任务不同。

场景文件写到 `scenarios/model-a-t25.json`，依次做到：

1. 打开 /login.html，填账号密码，点登录，等地址变为 dashboard
2. 点击左侧菜单"订单管理"，等订单表格出现（`#orderTable tbody tr`），读数据行数 → `orderRows`
3. 点击"导出"按钮（`#exportBtn`），等文本"导出成功"出现，读 `#toast` 的文字 → `toast`
4. 截图 `orders`；输出布局树 `orders`（root 为 `main`）
5. 断言无 console 错误

运行：`node tools/scenario-run.js scenarios/model-a-t25.json --out <场景执行器输出目录>`（目录由启动提示给出；没给就用 results/model/a-t25-out）。
有步骤失败时看输出里的 `×` 行和最后的 `RESULT` 行，改场景后重跑，最多重跑 2 次。

结果文件（路径由启动提示给出；没给就写 `results/model/a-t25.json`）：

```json
{ "orderRows": "", "toast": "", "retries": 0, "notes": "" }
```

值从 RESULT 行的 `values` 里抄。拿不到的写 "未获取"，不要编。
