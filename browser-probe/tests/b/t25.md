# 任务 b/t25：表单向导（校验提示、单选、下拉、复选、三步提交）

方式：写场景文件，用场景执行器跑（第二点五档）。不要用 Bash 直接开浏览器，不要修改 tools/ 下的脚本。

站点 http://127.0.0.1:4173，账号 admin / admin123。登录成功后跳到 /dashboard.html，再用 goto 打开 /b/index.html。

先读 `scenarios/README.md`。可参考 `scenarios/sample-b-wizard.json`，但本任务的数据和要读的值都不一样，照抄会答错。

页面元素：第一步 `#name` 名称、`#type` 下拉、地区单选 `#region1` 华东 / `#region2` 华北 / `#region3` 华南、`#email` 邮箱、`#next1` 下一步、`#err1` 错误提示；第二步 `#contact` 联系人、`#phone` 电话、`#remark` 备注、`#enabled` 启用复选框、`#next2` 下一步、`#err2` 错误提示；第三步确认表 `#confirm`（第 8 行是"启用"），`#submit` 提交；完成页 `#code` 编号、`#doneName` 名称。

场景文件写到 `scenarios/model-b-t25.json`，依次做到：

1. 登录，打开 /b/index.html
2. 第一步填：名称 云图教育，类型 服务商，地区 华北，邮箱 yt@example.com，点下一步
3. 第二步先填：联系人 林晓，电话 123，点下一步，读 `#err2` 的提示 → `phoneError`
4. 把电话改成 13900000000，备注 自动体检，取消勾选"启用"，点下一步
5. 第三步读确认表第 8 行的值（`#confirm tbody tr:nth-child(8) td`） → `enabledText`
6. 点提交，等文本"提交成功"，读 `#code` → `code`，读 `#doneName` → `doneName`
7. 截图 `done`；断言无 console 错误

运行：`node tools/scenario-run.js scenarios/model-b-t25.json --out <场景执行器输出目录>`（没给就用 results/model/b-t25-out）。失败最多重跑 2 次。
