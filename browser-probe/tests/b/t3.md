方式：只用 Playwright MCP 工具（名字以 `mcp__playwright__` 开头）直接操控浏览器（第三档）。禁止用 Bash 开浏览器，禁止 WebFetch，禁止读演示站源码推算答案。

站点 http://127.0.0.1:4173，账号 admin / admin123。登录成功后跳到控制台，再导航到 /b/index.html。

提示：browser_navigate 可能只返回快照文件链接，直接调 browser_snapshot 拿带 ref 的快照；填表可以用 browser_fill_form 或 browser_type；单选、复选用 browser_click；下拉用 browser_select_option。不要用截图工具。

2. 第一步填：供应商名称 云图教育，类型 服务商，地区 华北，邮箱 yt@example.com，点下一步
3. 第二步先填：联系人 林晓，电话 123，点下一步，读出红色错误提示 → `phoneError`
4. 把电话改成 13900000000，备注 自动体检，取消勾选"启用该供应商"，点下一步
5. 第三步的确认表里"启用"一行显示的是什么 → `enabledText`
6. 点提交，等"提交成功"出现，读供应商编号 → `code`，读"已收到 xxx 的资料"里的名称 → `doneName`
