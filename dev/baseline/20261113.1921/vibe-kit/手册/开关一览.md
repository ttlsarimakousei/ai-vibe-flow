# 开关一览

配置页"套件开关"里每一项是哪一版加的、默认是什么。回到[用户手册](../README.md)。

从 20261017 之前的版本升上来时，这几项强制改成新的默认值一次：自动压缩线 70%、到了交接线之后"不问，只提醒"、提交方式"关"、需求自动和 Apply 自动关闭（有会话正在 Apply 自动干活时，两个自动模式等下次更新再关）。之后的更新不再动，其它已有设置保留。配置页保存后立即生效，钩子登记变化需要重开会话。

"上下文快满时怎么办"（这一版起）：以前的连续工作的方式、交接线、自动压缩线、到了交接线之后四项合成两项，你原来的选择照样生效，配置页按原来的值显示。选了自动压缩，用到这个百分比压缩；选了提醒、问我，到这个百分比提醒或者问，再过 15 个百分点（最高 95）才压缩，以前这两条线是分开填的。
