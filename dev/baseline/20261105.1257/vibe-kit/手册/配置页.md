# 配置页和规范

配置页怎么开、配置放在哪、怎么加规范和改约定、检查怎么跑、模型路由删了之后少了什么。回到[用户手册](../README.md)。

## 配置页

敲 `/vk-config`：钩子起配置页、打开浏览器，屏幕上写着地址，不发模型请求。

- 用时才起，不常驻。端口优先 15731，被占了换一个，地址以屏幕上写的为准。
- 页面开着时每 30 秒发一次心跳。关了页面 3 分钟退出；起了 5 分钟没人开也退出。再用再敲。
- 只监听本机，只认本机连接和本机 Host；别的网站的页面发的请求不收，改东西还要带页面自己的请求头。
- 打不开：再敲一次 `/vk-config`；地址用 `127.0.0.1`，浏览器或系统代理要对本机地址直连。

改了开关，点页面底部的保存条，立即生效。

## 检查怎么跑

套件的检查都是钩子，全部走命令方式：每个检查起一个 node 进程，每次 0.3～0.9 秒。出错放行，记一条问题反馈。

已知问题：Claude Code 2.1.259、2.1.263 在脚本方式（`claude -p`）下，SessionStart 钩子慢一点、同时配了命令方式的 Stop 钩子时，答完不退出。和套件钩子的内容无关，交互着用不受影响。要在脚本里调 `claude -p` 的，给它加超时。

## 加规范、改约定

全局约定和提交规范每个请求都带着，每加一个字都是每个请求的成本，写短；OpenSpec 规范进流程时才送。你自己的约定和规范放 `~/.claude/vibe-kit/user/`，更新套件从不碰这个目录，卸载也留着：

- 加：在 `user/` 里放 `.md` 文件（文件名不以下划线开头的才生效），按文件名顺序接在套件的约定和规范后面。
- 去掉套件约定、规范里你不要的某一句：把那一句原样抄进 `user/remove.txt`，一行一句（不算行首行尾的空格，`//` 开头的行是说明），生成时去掉。套件以后改了这一句的说法，就去不掉了，要按新说法再抄一次。
- 停用套件的某条规范：给 `~/.claude/vibe-kit/rules/` 里那个文件的文件名加下划线前缀，以后更新不会把它重新启用。

改完运行一次（配置页保存开关时也会顺带生成）：

```
node "%USERPROFILE%\.claude\vibe-kit\install.js" --sync
```

不要再直接改 `~/.claude/vibe-kit` 里的 `CLAUDE.md`、`rules/*.md`：那是套件的文件，更新时换成新版。以前照老说明直接改过的，升级时和上次装的原样比：你新加的内容（带上它原来所在那一节的标题）挪进 `user/migrated-<文件名>.md`，你删掉、改掉的原句记进 `user/remove.txt`，照样生效；原文件备份在 `~/.claude/vibe-kit/backup/`。改过的套件技能、审查代理、斜杠命令照旧换成新版，先备份。这几种情况配置页顶上提示一次，点"知道了"不再提示。

## 模型路由删了之后

这一版起套件不管模型怎么连（2026-11-03 定的）。连模型的地址和 key 你自己配，比如用 cc-switch。

**升级时收回什么**：路由进程、开机自启的 `vibe-kit-router.vbs`、`router/`、`router-data/`（模型、key、用量、配置备份）、更早的 `~/.claude/model-router`、`config.json` 里的旧开关、路由用的状态文件。自动更新在新版第一次开会话时收，新版自检不过、装回旧版的时候这些都还在；手动安装装完当场收。收的结果在会话开始时说一句，中途失败下次开会话再试。

- key 删了找不回来。要留着的，升之前自己记好。
- 配置页点过"接上"的：`settings.json` 的 `ANTHROPIC_BASE_URL` 恢复成接上之前的地址。没有记录的不动，提醒你用 cch 切走。
- 端口上是别的安装的路由（多人共用一台电脑时）：不停别人的，只收自己的文件。

**少了什么**：

| 以前路由做的 | 现在 |
|---|---|
| 按角色分模型（审查用 sonnet）、出错换模型、限流先等再换、额度用完停用 | 没有了。审查子代理和主会话用同一个模型 |
| 配置页的"模型""用量"两页、状态栏的今天用量 | 没有了 |
| 半截回复保护：上游断了不把半截回复装成正常结束 | 没有了。2.1.120、2.1.259 会把没有结束标记的回复当成回完，看到回复断在半截就说"继续"。升 Claude Code 能好一些，套件没有替代 |
| 网关 413（请求太大）翻译成人话，快到上限时状态栏提前警告 | 没有了。默认压缩线 70% 顶着；真碰上敲 `/compact` |
| 五个高频检查在路由里跑，一次几毫秒 | 全走命令，一次 0.3～0.9 秒 |
