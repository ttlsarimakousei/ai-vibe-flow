# 开关一览

配置页"套件开关"里每一项是哪一版加的、默认是什么。回到[用户手册](../README.md)。

本次升级把这几项强制改成新的默认值一次，不管你之前选的是什么：自动压缩线 70%、到了交接线之后"不问，只提醒"、提交方式"关"、需求自动和 Apply 自动关闭（有会话正在 Apply 自动干活时，两个自动模式等下次更新再关）。之后的更新不再动，其它已有设置保留。配置页保存后立即生效，钩子登记变化需要重开会话。
